## 0. 現状の区別・修正原則

- **添削された9ページの初期ドラフト**は第5〜7章に「執筆予定」が残り、先行研究の説明・比較・導出根拠が薄い。**別途GitHubで記録されている2026-10-16の統合初稿**は1〜7章約37,998字の別の進行段階にある。添削の指摘を後者にも適用するが、後者に既に存在する第2・3・5〜7章の詳細草稿と原典監査を読み比べ、既存成果を消さずに重複・不足を判定する。2026-10-17/19以降の原稿に同じ問題が残るかは未照合。
- **中心となる研究**は構造化文献比較による「支援中の成績／支援を外した独立学習成果の違い→説明できる条件→設計要件候補」。実際の教育上の改善・長期的な効果を検証したものと主張しない。
- 本人採用済みの**案A：AIなし独立成果を主指標／自己調整学習（SRL）は補助指標**を維持する。変更が必要なら事前に候補文と根拠を提示する。
- 「AI利用群は多くの研究でAIなしテストが低い」とは、現時点の選定結果だけで一般化できない。主分析の厳格M1はL-001・L-027の2研究で結果の方向も一様ではない。負・正・非有意の知見、母集団、教科、比較条件、測定時点を同じ条件で整理する。AIの利用率と学力への因果的影響を直接結び付けない。
- 添削には「今回は中学生」とあるが、**現行RQは中等教育（中高生）**、厳格M1は高校研究を含む。中学生だけに狭めると主たる根拠を失う可能性がある。**中高生中心を維持し、中学生への適用は区別**するのが当面の推奨。中学生限定案は対応する直接研究の量・質を再点検し本人・指導教員の判断後に決定。
- 形式は2026年度学部要領の**20,000字程度**、2026-12-20 23:59期限、本人指定の**游明朝Regular 10.5pt**を参照。現在の統合稿の約38,000字からの圧縮が必要。大学の引用方式別添は未入手のため断定しない。

## 2. 推奨する6章の構成案（採用は本人確認後）

**論理順を優先**し、現行章番号に固定しない。

1. **序論：研究背景・社会課題** — 国内外の利用状況と既存の学習成果上の懸念。研究で扱える解の範囲を明示（詳細のRQ定義は第2章後半）。
2. **先行研究と研究課題** — まず各研究の実験と知見を具体的に説明し、研究空白を抽出。次に中等教育を選ぶ理由（中学生と高校生の違いを含む）、概念と成果指標、目的、Q1〜Q3を確定的に記載する位置とする。
3. **研究方法** — 検索履歴、採否基準、原典監査、比較コード、品質評価、比較可能性、誤差・限界と「なぜこの方法か」。
4. **文献の比較分析** — 課題遂行/直後AIなし/遅延/転移別に、正・負・非有意と介入条件の違い、反対事例を分析。研究間の違いを因果と取り違えない。
5. **設計要件の導出と考察** — DR-01〜12を根拠強度、反例、具体的な授業での動作案、評価手順と対応付ける。学校での運用制約も分ける。
6. **結論・限界・今後の研究** — Q1〜Q3への暫定回答、文献研究の限界、設計の未検証性、将来の実証計画。

※中高生を対象にする既存知見と中学生へ外挿する判断は分ける。第2章に先行研究の「概要・位置づけ」、第4章に「同じ基準に基づく横断比較」を置き、二重記述を避ける。

## 文献を追加する際の手順

1. 資料の利用・保存条件を確認し、Google Drive上記フォルダへ原本を保存する。著作権、機関限定アクセス、共有権限を守る。
2. 保存結果を読み戻し、**ファイルID・タイトル・実際に存在すること**を確認する。単なる検索ヒットや取得試行を保存完了と書かない。
3. 文献台帳 `references/literature-matrix.md` で同一資料・異版・DOIを照合し、新規なら文献IDを採番する。既存29ファイルはID未照合のため勝手に新しい件数に加えない。
4. `sources/` の個別メモに「原本はGoogle Drive」「実ファイル名」「確認した版・日時・取得先」を記録する。DriveファイルID／個別リンクは公開して差し支えない資料に限ってGitHubへ書く。**学内限定・非公開資料の個別URLは公開リポジトリに掲載しない。**
5. 本文が読めた範囲と引用可能な箇所を区別して記録し、台帳・メモ・レビューを整合させる。文献収集ができたことと学術的評価完了を混同しない。
6. 失敗したアップロード、重複、版の差、権限不足は明示する。アクセス不能なら原本未確認として扱う。

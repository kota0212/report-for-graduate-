# 2026年度 学士論文「卒業論文」提出要件（政策科学部・一次資料確認）

確認日：2026-10-16。出典：政策科学部（2026年5月）「⑤2026年度『卒業論文』の提出について.pdf」（全2ページ、本人提示）。ユーザー添付原典を確認済み。PDF原本そのものはPublic GitHubに転載しない。

## 大学公式の要件

| 項目 | 指示 | 出典 |
|---|---|---|
| 卒業要件 | 卒業論文の提出、「学士論文」単位の取得が必要 | p.1 (1)、p.2 |
| 文章量 | **1人につき20,000字程度**。20,000字以上という絶対下限ではない。外国語は約5,000語 | p.1 (2)① |
| 形式 | **Word・A4縦置き・横書き** | p.1 (2)② |
| 1ページ目 | 第1行を左寄せにしてゼミ名、回生、氏名。第2行以降に日本語タイトル、外国語タイトル、日本語要約（1ページ程度）。**全体を1ページに収める** | p.1 (2)② |
| 2ページ目 | 日本語タイトル、外国語タイトル、外国語abstractのみ。**欧文150語程度**（中国語140字程度） | p.1 (2)③ |
| 3ページ目以降 | 目次、本文を開始 | p.1 (2)④ |
| 引用文献 | **別添資料を参照**。この添付PDFに記載方法の詳細はないため**未確認** | p.1 (2)⑤ |
| 評価 | RQ・目的の明確さ、結論に至る論理の整合性と裏づけ、指導教員の指示 | p.1 (3) |
| 秋学期の期限 | **2026-12-15（火）〜12-20（日）23:59【厳守】** | p.2 (4) |
| 提出先 | **moodle＋Rの「学士論文」各クラスコース**。詳細は担当教員に確認 | p.2 (4) |
| 補足 | 指導教員による再提出指示の可能性。124単位以上と学士論文単位の両方が卒業に必要 | p.1–2 |

## 執筆への適用

- **過去のメモにある「20,000字以上」「期限未確認」は履歴であり、現行の正式要件ではない。** 20,000字程度と期限12/20 23:59が一次資料で確認された。
- 執筆管理上の約22,000字という目標は提案として残せるが、大学公式の最低字数・上限ではない。本文、参考文献、脚注、図表などの算入範囲はこの資料では未指定。
- この資料は独自調査・実験・アンケート必須とは書いていない。ただし指導教員の指示や文献比較のみの妥当性確認は別問題。
- **フォント、文字サイズ、余白、行間の指定は公式PDFに存在しない**。本人希望に基づく[過去卒論の形式](thesis-format-2026.md)を暫定使用。
- 参考文献様式の別添を入手するまでAPA等を「大学指定の最終形式」として確定しない。

# 卒論ダッシュボード（Human View）

更新日：2026-10-12 ／ このページは人向けの入口です。詳細の正本はリンク先を更新し、ここへ全文複製しません。

## いまの結論

**文献を片っ端から「使える／使えない」に移す前に、仮の研究問いと資料の全体像を往復して確認する** のが合理的です。問いの確定前の資料は「保留」にしておくことで、重要文献の誤除外を防ぎます。

## 進行状況

| 領域 | 現在地 | 次に必要なもの |
|---|---|---|
| テーマ・RQ | 本人提示テーマあり、正式承認未確認 | 中心RQと対象の絞り込み、正式承認の確認 |
| ゼミ要件 | 未確認 | 文字数・提出日・倫理審査・指導条件の正式情報 |

| 調査設計 | 方法選択の基準を作成済み | RQとデータの入手可能性 |
| 執筆 | 未着手扱い | 研究の骨格と出典が確認できてから開始 |

## 優先順位

1. 仮題・仮RQ・調査対象・卒業要件を取り出す（既存の会話や資料を再利用する）。
2. iCloud「卒論」を一覧化し、重複・出典不明・本文未確認を識別する。初期判定は保留を許容。
3. 核となる文献について「主張／根拠ページ／用途／限界」を記録し、論点別に比較する。
4. 独自に答えられる問いかを確認し、データ取得・倫理・分析可能性を点検してから方法を確定する。
5. 小規模な予備調査またはデータ試験を経て、章立て・本調査・執筆へ進む。

詳しくは [研究計画](research-plan.md)、[計画の再評価](plan-review.md)、[タスク](tasks.md)。

**未実施**：iCloud原本の分類、全ての優秀卒論の個別分析、独自調査、論文執筆。

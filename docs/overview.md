## いまの結論

**文献を片っ端から「使える／使えない」に移す前に、仮の研究問いと資料の全体像を往復して確認する** のが合理的です。問いの確定前の資料は「保留」にしておくことで、重要文献の誤除外を防ぎます。

## 優先順位

1. 仮題・仮RQ・調査対象・卒業要件を取り出す（既存の会話や資料を再利用する）。
2. [Google Drive「ゼミ（卒論）」](source-storage.md)の原本29ファイルを文献台帳19件・過去iCloud資料と突合し、重複・出典不明・本文未確認を識別する。初期判定は保留を許容。
3. 核となる文献について「主張／根拠ページ／用途／限界」を記録し、論点別に比較する。
4. 独自に答えられる問いかを確認し、データ取得・倫理・分析可能性を点検してから方法を確定する。
5. 小規模な予備調査またはデータ試験を経て、章立て・本調査・執筆へ進む。

詳しくは [研究計画](research-plan.md)、[計画の再評価](plan-review.md)、[タスク](tasks.md)。

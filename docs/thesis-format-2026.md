## 2026-10-16 ユーザー指定フォント：現行の固定ルール

ユーザーがWordのフォントメニューの画像で選択したのは**「游明朝 Regular、10.5」**である。前回AIが記録・出力した「MS明朝10.5pt＋Times New Roman」は**画像の書体と異なる誤認**だった。前々回の「MS Pゴシック＋Arial」も不採用。これらを**今後の標準にしない**。

| 対象 | 現行指定 |
|---|---|
| 和文本文 | **游明朝（Yu Mincho）、Regular、10.5pt** |
| 欧文・数字 | **游明朝（Yu Mincho）、Regular、10.5pt**を基本。Times New Roman等への自動変更は禁止 |
| 見出し・題名 | フォントファミリーは**游明朝**に統一し、見出し階層に応じてサイズ・太字は調整できる |
| 脚注・表・要約 | 原則游明朝。正式要領による別指定を優先 |
| Word内部設定 | デフォルト本文スタイルだけでなく、各スタイル・直接書式、欧文／日本語（eastAsia）文字も游明朝に統一 |

**この書体は本人指定の制作ルールであり、政策科学部が指定した公式フォントではない。** 同学部の2026年度提出要領は字体・ポイント数を指定していない。公式の要約・ページ構成は厳守する。

**ChatGPT・Codex共通**：新規Word・既存卒論ドラフトの修正では、この固定ルールを参照。指定したファイルが游明朝で表示されるかの確認が必要。環境に游明朝がない場合、Wordのフォント設定自体は游明朝に指定できるが、代替表示によるスクリーンショットを「本人のMac上と完全同一」と断定しない。

## 必須の構成

1. **1ページ目**：1行目に「鐘ヶ江ゼミ・4回生・氏名」を左寄せ → 日本語題名 → 外国語題名 → 和文要約。1ページに収める。
2. **2ページ目**：日本語題名 → 外国語題名 → 英語約150語のabstractのみ。
3. **3ページ目以降**：目次と本文、最後に参考文献（正式引用ルールは別添取得後に確定）。

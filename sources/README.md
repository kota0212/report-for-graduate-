# 文献ごとの判定メモ（原本は保存しない）

- [usable/](usable/)：今回のRQ・背景・方法などに**具体的な用途がある**文献のメモ
- [not-usable/](not-usable/)：現時点で用途が確認できない文献のメモ。削除せず理由を残す
- [pending/](pending/)：本文未確認、仮RQ未確定などの保留メモ

分類は相互排他的に管理し、再判定したらファイルを対応する場所へ移し、[文献台帳](../references/literature-matrix.md)の状態も更新する。ファイル名の例は L-001-short-title.md。出典確認・書式は [テンプレート](../references/source-note-template.md)。

**iCloud「卒論」の原本フォルダでのファイル移動と、GitHub上のメモ分類は別作業。** GitHub側のメモを作成しただけでiCloudの移動・分類が完了したとは記録しない。著作権・学内限定・個人情報入りのファイルは公開GitHubに置かない。

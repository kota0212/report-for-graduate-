# 文献管理・根拠の記録ルール

文献の登録先は [literature-matrix.md](literature-matrix.md)。各文献の詳細は [source-note-template.md](source-note-template.md) に従い、判定に応じ [sources/](../sources/README.md) に1文献1ファイルで記録。

## 台帳の基本

- IDは **L-001, L-002...** とする。現在は実在の個別文献を検証していないため、仮の行を実際の文献として登録しない。
- 同じ資料を重複登録しない。卒論「論文集」は収録論文ごとに研究文献のIDを付ける。
- 書誌は確認した著者、発行年、タイトル、媒体、掲載情報、DOI・URL等を記録。存在しないDOIを作らない。
- Google Drive原本の**全文や秘密情報をここへ貼り付けない**。公開に適さない個別ファイルURLも書かない。原本保存・リンクの詳細は[原本保管ルール](../docs/source-storage.md)を参照。旧iCloudの所在は履歴としてのみ扱う。
- 本文未読なら「タイトル・要約のみ確認」と書き、正確なページ引用を作らない。

## 二軸の判定を行う

| 軸 | 評価 |
|---|---|
| 今回の研究への関連度 | 高／中／低／未判定：RQ、対象、理論、背景、方法、構成のどれに関係するか |
| エビデンスの信頼性 | 高／中／低／未判定：一次資料か、研究方法は適切か、出典追跡できるか、対象と時期は適合するか |

「使える／使えない／保留」は**作業上の分類**であり、論文全体の学術的評価ではない。高品質でも関連が薄い研究、関連が強くても方法上の問題がある研究を区別する。低品質資料は根拠として安易に使わず、批判的検討の対象にする。

## 利用箇所に必要な最小情報

1. 本文の該当ページ・節・表（確認済みかを明記）
2. そこで述べられている事実・主張と条件、可能なら根拠データ
3. 卒論での使い方（背景／理論／先行研究／方法／比較／構成のみ）
4. 限界、引用にあたり追加確認が必要な点
5. 採否判断日・再判定の条件

直接引用は必要最小限にし、著作権と学内の引用規定を守る。二次情報を通じて知った原典は原典未確認と表示する。

## 文献検索ログ

検索時は「検索日／検索サービス／検索式／ヒット件数（確認できた場合）／採用理由／除外理由」を文献台帳付記か調査メモに残す。学術検索結果を実際に取得していない場合、検索済みとしない。


## 2026-10-12以降の追加・更新ルール

- 台帳が登録状態の正本。[index.md](index.md)は探す入口、[APA一覧](apa-reference-list.md)は書誌表記、詳細MDは内容の根拠、[横断レビュー](../docs/literature-review.md)は比較分析。
- A＝使用候補／usable、B＝要確認／pending、C＝使えない／not-usable。Cは関連性が低い通常ケースに加え、撤回等による不採用を含む。L-014は関連性高・信頼性低と明示し、関連性低と偽らない。
- 本文未確認は原則B。正式テーマ承認前でも、本人提示の範囲に具体的用途があり本文を確認したものは暫定Aにできる。正式採用とは区別する。
- 本文確認済みは、対象版の方法・結果・限界等を確認した範囲を意味し、補足資料全監査・全引用追跡の完了ではない。政策資料と研究論文を件数でも分ける。抄録の数値を本文精査した値と扱わない。
- 全著者・年・正式題名・媒体・DOI・URLを照合。DOIや掲載ページがない場合は該当なし／未確認を分ける。新規IDは最大番号＋1、今回以降L-015。削除IDを再利用しない。
- 重複はDOIを小文字化して照合し、DOIなしは題名・著者・年と版を確認。同一研究のプレプリント／掲載版は1ID、使用版と差分を記録する。
- 再分類は詳細MDを移動して台帳、index、APA管理リンク、横断分析のリンクを同時修正。既存分析は失わせず更新理由を残す。
- 数値は率、相対変化、割合ポイント、OR、標準化効果量を区別。非有意差を同等性と呼ばない。サブ群内有意差を群間差と呼ばない。
- コピー用APAはID・分析リンクなしの段落とし、管理リンクを別表へ置く。書誌未整合は「要確認」、撤回は正式コピー一覧から除外。3人以上の本文引用は初回からet al.。日本語の姓名・原題は維持し、最終提出時に学内規定と整合。
- 新規書誌・本文・訂正を確認した日、URL、確認節・表・版を記録し、根拠とAI考察を分離する。
- [今回の検索ログ](search-log-2026-10-12.md)を継承し、次回は別日付のログを追加する。

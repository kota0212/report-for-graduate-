# 文献管理・根拠の記録ルール

文献の登録先は [literature-matrix.md](literature-matrix.md)。各文献の詳細は [source-note-template.md](source-note-template.md) に従い、判定に応じ [sources/](../sources/README.md) に1文献1ファイルで記録。

## 台帳の基本

- IDは **L-001, L-002...** とする。現在は実在の個別文献を検証していないため、仮の行を実際の文献として登録しない。
- 同じ資料を重複登録しない。卒論「論文集」は収録論文ごとに研究文献のIDを付ける。
- 書誌は確認した著者、発行年、タイトル、媒体、掲載情報、DOI・URL等を記録。存在しないDOIを作らない。
- iCloud原本の**全文や秘密情報をここへ貼り付けない**。所在は個人を特定しない範囲の相対的な説明に留める。
- 本文未読なら「タイトル・要約のみ確認」と書き、正確なページ引用を作らない。

## 二軸の判定を行う

| 軸 | 評価 |
|---|---|
| 今回の研究への関連度 | 高／中／低／未判定：RQ、対象、理論、背景、方法、構成のどれに関係するか |
| エビデンスの信頼性 | 高／中／低／未判定：一次資料か、研究方法は適切か、出典追跡できるか、対象と時期は適合するか |

「使える／使えない／保留」は**作業上の分類**であり、論文全体の学術的評価ではない。高品質でも関連が薄い研究、関連が強くても方法上の問題がある研究を区別する。低品質資料は根拠として安易に使わず、批判的検討の対象にする。

## 利用箇所に必要な最小情報

1. 本文の該当ページ・節・表（確認済みかを明記）
2. そこで述べられている事実・主張と条件、可能なら根拠データ
3. 卒論での使い方（背景／理論／先行研究／方法／比較／構成のみ）
4. 限界、引用にあたり追加確認が必要な点
5. 採否判断日・再判定の条件

直接引用は必要最小限にし、著作権と学内の引用規定を守る。二次情報を通じて知った原典は原典未確認と表示する。

## 文献検索ログ

検索時は「検索日／検索サービス／検索式／ヒット件数（確認できた場合）／採用理由／除外理由」を文献台帳付記か調査メモに残す。学術検索結果を実際に取得していない場合、検索済みとしない。

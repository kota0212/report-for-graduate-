# Step 4｜設計要件 DR-01〜12 の根拠・反証・検証対応表（2026-10-16）

**位置付け**：卒業論文第6章で提案する設計要件の根拠追跡表。既存 [Q1–Q3／DR再評価](../docs/evidence-synthesis-2026-10-16.md) と [第5章草稿](../docs/chapter-5-comparative-analysis-draft-2026-10-16.md)を継承し、今回は中核7研究の原典監査で確定・保留となった条件を組み込んだ。**既存のDR-IDと名称・研究目的を破棄せず、学習効果の確実性だけを再評価**する。表は研究者による比較に基づく**要件提案**であり、12項目の各UI・機能の効果を個別RCTで実証したものではない。

## 1. 証拠の区分と主張の強さ

- **A：中等教育で直接確認できる根拠**。ただし確認されたアウトカムと機能の範囲のみ。DR-01では「支援中とAIなし評価を分ける意義」に直接の根拠があることを指し、UIの学力改善効果を意味しない。
- **B：根拠に基づく合理的な設計候補**。複合介入の比較、間接研究、一般理論から説明できるが、**一つの機能に由来する因果効果は特定できない**。
- **C：追加研究で検証すべき仮説・機能候補**。有効性は未確立。中等教育での試験が不十分、結果が非有意、探索的など。
- **D：学校導入に伴う規範・制度・安全上の要件**。権利・制度上の必要性を論じるための区分で、**学力向上を実験で示す区分ではない**。
- **直接性（M1/M2/Q/I/B/X）と根拠区分（A/B/C/D）は別軸**。同一要件に複数区分を併記できる。例えばDR-03は安全運用D＋「検証済み説明が成績を改善する」機能仮説B。ある研究のAIなし評価がM1でも、その実験で独立操作していないヒントの一機能をAにしない。

**現行の原典確定範囲**：中等教育でAIなし事後試験が明示された直接主分析 **M1＝L-001、L-027の2件**。**M2＝L-005（次問初回は支援なし・AIアクセス全体の禁止ではない）、L-017（10〜17歳の混合年齢、AIなし直後／1週後）**。**Q＝L-009、L-024（評価時AI可否不明）、L-029（全群AI、SRL補助）**など。24件の登録資料とM1の2件を同数とみなさない。未登録WPのN-001/002を確定効果の根拠にしない。

### DR-01／DR-02／DR-10／DR-12の違い

- **DR-01**：支援の効果を**どう測定するか**。機能追加で学力が上がると予測する要件ではない。
- **DR-02**：一つの問題を解く**その場で**本人の初回試行後に援助する設計候補。
- **DR-10**：単元・授業の**学習前の診断や想起試行**と、最終学習成果の測定を区別する。
- **DR-12**：複数問題・授業にわたり**時間経過に応じて**支援を減らす効果の仮説。DR-02とは独立した検証が必要。

### 特に避ける過剰解釈

1. L-001の「約17%低い」は高校数学の**短期・対照平均に対する相対差**。数年後の全国学力低下でも、17ポイントの低下でもない。
2. L-027の有意差は**AI＋ガイド＋個別FB**と通常AIでの**複合介入**。学級割付のクラスタ推論が不明。
3. L-005のOR1.07は**正答オッズ**で、次問初回は支援前だがAI利用全面禁止ではない。中学7年生に一律7ポイントの利益を保証しない。
4. L-017の1週間保持は10〜17歳の混合集団で、主要群間差が非有意。中等だけの確定効果ではない。
5. L-029は**全群AIを利用し、全てのAIが完成正答提示を抑制**。SRL・教科知識の主要指標は多くが非有意、130/371人（35%）脱落。問いかけの絶対優越を支持しない。
6. L-009とL-024の評価時AI禁止は原文監査でも未明示。**AIなし成績に関するM1の結果へ編入しない**。
7. 「非有意」は効果なし・同等性の証明と同義ではない。限界を含めて判断する。

## 3. 機能を統合する際の提案（**実装済みシステムではない**）

DRを単なる12機能の足し算ではなく、以下の**学習過程×検証・学校運用**として組み立てる。

1. **学習前：目標・事前試行・既有知識の把握**（DR-10/05）。事前試行による学習効果と、診断目的の得点は分ける。
2. **学習中：自分で考える→必要に応じ支援→理由・誤りを確認**（DR-02/03/04/06）。AIが完成答案を常に出さないだけで成果を保証しない。理解困難時の説明や教員への相談を認める。
3. **反復・学習後：振り返り、支援調整、AIなし新問での評価**（DR-08/11/12/01）。短期と遅延、同問と別問を区別する。
4. **全段階を支える横断条件：教師の判断・学校の制度・プライバシー**（DR-07/09）。人間の責任と代替手段を確保する。

**例示的な数学の1問の流れ（有効性未検証）**：①生徒が最初に式や考え方を書く（DR-02）→②AIは誤りに対して一つのヒントを示す（DR-02/03）→③生徒が自分の言葉で修正理由を説明（DR-04）→④必要なら先生へ相談（DR-07）→⑤似た新問をAIなしで解いて確かめる（DR-01）→⑥学習記録を見て支援量の調整を**試験的に**検討（DR-05/08/12）。この一連の方法を比較した中等教育RCTが存在すると**主張しない**。

## 4. 第6章の研究上の独自性と判断

本研究の**独自性の主張**は、新発見の学習効果や12機能の効果実証ではない。既存の正・負・非有意結果に対し、**「評価時のAI可否を確認する → 支援条件・複合性と研究品質を分ける → DRの根拠区分／反例／実験で必要な追加検証を一対一で表示する」**という構造化された提案過程にある。

- **必ず行うべき評価・学校運用の区別**：DR-01（評価妥当性）、DR-03の品質・安全部分、DR-07/09（運用・権利・安全）。
- **研究から合理的だが実証範囲が限定された設計候補**：DR-02、DR-04、DR-08の振り返り・測定、DR-10の診断／プレテストの区別、DR-11の曝露記録。
- **検証を前提にした探索的機能**：DR-05、DR-06、DR-12、DR-08の反省促進効果、DR-10のGenAIとの組合せ効果、DR-11の介入タイミング。

**結論の上限**：この原典セットだけから、DR-01〜12の「すべてが学力を上げる」「自律性や依存リスクが改善する」と因果証明することはできない。最終章では、中等教育の直接M1が現時点2本という制約、教育段階・教科・短期結果・国別制度の違い、教師負担・個人情報・公平性を限界に残す。

# 卒業論文プロジェクト

卒業論文のテーマ設定、先行研究の整理、調査設計、執筆計画を一元管理するリポジトリです。

## 現在の状態

- 研究テーマ・研究課題：未確定（確認待ち）
- 先行研究資料：2023〜2025年度のゼミ推薦卒業論文集PDFがLibrary上で確認済み。個別論文のテーマ適合性は未判定。
- 卒論資料の分類：元資料と分類用フォルダの実体は未確認。iCloud内のファイルを確認できた後に分類する。
- 卒論本文やPDF原本はここに複製せず、出典情報、評価、使える箇所、用途、調査メモを記録する。

## フォルダ構成

- `docs/research-plan.md`：研究計画、作業手順、不足情報、進捗
- `references/literature-matrix.md`：文献レビュー用の比較表
- `sources/usable/`：使えると判定した資料の分析メモ
- `sources/not-usable/`：今回の研究には使わないと判定した資料の記録
- `sources/pending/`：判定保留資料の記録

## 判定の考え方

「使える」は論文全体をそのまま流用できるという意味ではありません。研究テーマとの関連に応じて、先行研究、概念・理論、調査方法、分析手法、背景資料、論文構成のどこに使えるかを個別に記録します。文章・図表の転載は行わず、引用が必要な場合は原典を確認します。

## 次に確認すること

1. iCloudの「卒論」資料と「使える」「使えない」分類先を確認する。
2. 研究テーマ、対象、問い、ゼミの条件を確定する。
3. 個別資料を評価し、理由と利用目的を記録する。
4. 必要な先行研究を追加検索し、調査設計へ進む。

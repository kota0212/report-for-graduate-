## 原本とリポジトリの分担

- **[Google Drive「ゼミ（卒論）」](https://drive.google.com/drive/folders/1za-s4pfKumktTaYw8ySywjiUTPxsCuMF)：2026-10-16以降、卒論文献の**原本ファイルの正本保存先**。フォルダ直下に29PDFを確認したが文献台帳19件との照合は未完了。既存のiCloud原本移動は今回行っていません。詳細は[原本保管ルール](docs/source-storage.md)。
- **このGitHub：文献の書誌情報、本文確認済みの箇所、用途、研究計画、調査設計、文章草稿（公開してよい範囲）の正本**。原本PDFや学生サイトの非公開資料は置きません。
- **Obsidian：プロジェクトへのリンクのみ**。同じ計画のコピーを正本化しません。

**重要：Google Driveフォルダは確認時点で「リンクを知る全員が編集可能」でした。権限の制限が必要です（共有設定の変更は未実施）。**

このリポジトリは現時点で **Public（公開）** です。著作権資料、未公開の調査回答、氏名・連絡先、認証情報、個人を特定できる情報は絶対にコミットしないでください。安全に公開できるか判断できない情報はGitHubへ保存しません。

過去の優秀卒論（2023〜2025年度）は、**構成・RQの明確化・方法の適合性を学ぶ参考例**。自身の研究テーマの先行研究や、方法の正当性を自動的に保証するものではありません。

## 更新方針

テーマ、対象、データ、指導教員の要件が確定したら [研究計画](docs/research-plan.md) と [タスク](docs/tasks.md) を更新します。文献を判定した場合は台帳と個別メモを対応させ、未検証の引用やページ番号を作らないでください。
